# FilingDelta

**Research question:** do changes in the language of SEC filings (10-Q / 10-K MD&A) show up in stock prices, and with what lag?

Full day-by-day plan: `docs/plan.md`. Project overview and known issues: `README.md`.

## Conventions

- Comments say *why*, not what. Thresholds and other choices that affect the analysis are explained where they are set, with the evidence behind them.
- Run new code on **MSFT first**, check the output, then all 11 tickers.
- "Saved" is not "correct": look at actual output (lengths, first lines, sample rows), not just exit codes. Silent parser failures already cost the big banks.
- Commit messages: short imperative, like the existing history.
- Keep the README's Roadmap and Known issues up to date when something lands.

## Environment

- Python 3.13, venv at `.venv/` (`source .venv/bin/activate`).
- Run everything as modules from the project root: `python -m src.<module>`.
- Key libraries (pinned in `requirements.txt`): edgartools 5.62, pandas 3.1, pyarrow, RapidFuzz, scipy, yfinance 1.8, sentence-transformers (model BAAI/bge-small-en-v1.5, cached in ~/.cache/huggingface), matplotlib.
- SEC requires an identity on every request: `SEC_IDENTITY` in `src/config.py`. edgartools caches downloads in `~/.edgar_cache`.
- `data/` is git-ignored; everything in it is regenerated by the pipeline.

```bash
python -m src.earnings                # match filings to earnings 8-Ks (network); --tickers: print only
python -m src.event_study             # offline; --tickers: print only
```

## Design decisions

- **Universe:** 11 tickers in 4 sectors: banks JPM, MS; tech GOOGL, MSFT, NVDA; energy XOM, CVX, COP; consumer WMT, PG, KO. BAC, WFC, C, GS, PNC, USB excluded: edgartools 10-Q MD&A extraction fails silently or returns the wrong section for them (details in notebook 01).
- **Section:** MD&A only (10-Q Part I Item 2 = `part_i_item_2`; 10-K Part II Item 7 = `part_ii_item_7`). Risk Factors YoY from 10-Ks is backlog.
- **Window:** last 6 10-Qs + 2 10-Ks per ticker (= 8 quarters; no Q4 10-Q). This gives only 3 YoY pairs per ticker; raising `n_10q` to ~9 is under consideration.
- **Pairing rule** (`src/pairs.py`), on fiscal year/quarter, never calendar dates:
  - `yoy`: 10-Q vs same fiscal quarter last year (primary; removes seasonal wording)
  - `qoq`: 10-Q vs previous 10-Q in the same fiscal year (Q1 has none)
  - `annual`: 10-K vs prior 10-K (10-K MD&A is structured too differently to compare with a 10-Q)
  - amendments excluded from pairs
- **Fiscal quarters** (`fiscal_quarter()` in ingest.py): derived from SEC's `fiscal_year_end` (MMDD). Fiscal year named for the calendar year it ends in (MSFT quarter ending 2025-09-30 = FY2026 Q1). Dates in the first 7 days of a month count as the previous month, for 52/53-week calendars (KO Q2 2026 ended 2026-07-03).
- **Acceptance time:** from `filing.header.acceptance_datetime` (SGML header, US Eastern), not `filing.acceptance_datetime` from the filings list, which edgartools documents as sometimes hours off. Accepted at/after 16:00 ET -> event day is the next trading day (`accepted_after_close` in the manifest).
- **Diffing:** order-independent paragraph matching. difflib's positional diff fails on moved / lightly edited paragraphs (notebook 02). Mask numbers, %, $ and date phrases before comparing so number-only updates are separated from real language changes.
- **Diff matching** (`src/diff.py`): mask also covers period words ("three months", "second quarter"); RapidFuzz token_sort_ratio, case-insensitive; optimal one-to-one assignment (scipy linear_sum_assignment), not greedy; match needs score >= 65 within the same section, >= 80 across (sections compared after masking); +5 same-section tie-break inside the assignment only. Thresholds set by reading samples per score band, no clean valley in the distribution. Labels on exact text: unchanged / numbers_only / reworded / added / removed. No `moved` flag: tried and dropped (section labels too noisy; 0 of 3 correct in the hand check).
- **Embeddings** (`src/embed.py`): local `BAAI/bge-small-en-v1.5` (512-token limit truncates 0.2% of paragraphs; MiniLM's 256 would truncate 1.4%), normalized, text paragraphs sorted by (accession_no, para_no). Masked variant = `mask_direction(mask(text))` for matching; raw variant kept for retrieval. Embedding matching thresholds (`EMBEDDING` in diff.py): cosine >= 0.86 same section, >= 0.92 across, +0.01 tie-break; from same-section rate per 0.02 band + ~8 samples per band on MSFT/JPM/XOM/KO, never from labels/diff_handcheck.csv (kept for evaluation). Direction masking is for matching only; label() still uses mask(), so flips stay `reworded`.
- **Event study:** market model (OLS, simple returns on adjusted closes) vs SPY (primary) and sector ETF (`SECTOR_ETF` in config; GOOGL -> XLC), estimation window -250 to -30 trading days (need >= 200 days), CARs [0,+1], [-1,+1], [0,+5], SCAR = CAR / (sigma * sqrt(L)). Event day = acceptance day, or next trading day if at/after 16:00 ET (np.searchsorted on the price calendar, so weekends / market holidays roll forward).
- **Earnings dates:** from SEC, not a price vendor: latest 8-K with Item 2.02 accepted after period end and at/before the filing, within 60 days; header acceptance time. Same CARs computed for the earnings event; `earnings_in_window` / `trading_days_after_earnings` in events.csv mark confounded filing windows.

## Known data quirks

- MD&A word counts range ~4.4k (NVDA 10-Q) to ~64k (JPM 10-K).
- Page junk differs by company: MSFT "PART I"/"Item 2"; GOOGL "Table of Contents  Alphabet Inc."; JPM/MS/PG/COP footers with the page number inside. clean.py only drops repeated short lines *near a page break*: dropping every repeated short line (first try) removed real segment headings and sentences that differ only in numbers.
- Page-split joins only when clearly mid-sentence (second half starts lowercase, or first half's last word is lowercase / ends in a comma, and second starts with a letter): joining any two text blocks glued tables, bullets and footnotes to neighbours (JPM had 807 "joins").
- XOM 2026 10-Qs (2026-03-31, 2026-06-30) are hard-wrapped by edgartools: blank line after every printed line. The join rule fixes them (130-150 joins each, vs 0-2 for other XOM filings); median paragraph length now in line.
- CVX page header is 15 words, so REPEAT_MAX_WORDS is 20, not 12.
- Known clean.py misses: a few page-top headings dropped (JPM "Quarterly results", XOM "Volume / Mix", KO/PG "Nine months ended ... versus ..."); header-heavy tables tagged text; chart labels sometimes joined to the next paragraph.
- Check per-filing join counts and median paragraph length after any clean.py change: an outlier filing (like XOM 2026) hides in ticker totals.
- MD&A length seems to grow through the fiscal year (Q1 shortest): check if real before normalizing.
- `filing_date` is the next business day for filings accepted after 17:30 ET (all 8 GOOGL, 1 PG): never use it as the event date.
- Accepted after close for all 8 filings: MSFT, NVDA, GOOGL, JPM, MS, PG, WMT. COP, CVX, KO always intraday; XOM 2 of 8 after close. After-close does not mean "with earnings": JPM, MS, WMT file 2-4 weeks after results. Not yet checked against actual earnings dates.
- Read the manifest with `dtype={"fiscal_year_end": str}`, or "0630" loads as 630.
- CVX, JPM, XOM 10-K Item 7 runs into Item 8 (management's report, auditor's report; 4-22% of words). Validation doesn't catch it; clean.py cuts at the first whole-line Item 8 heading. XOM 2024 10-K lists those headings in a table of contents (line 15, with page numbers), so never cut on a plain substring match.
- diff.py: ~1 in 4 matches in the 65-80 band is a wrong partner (template look-alikes). Hand check (`labels/diff_handcheck.csv`, 24 rows): fuzzy 20 correct, embedding 24 (rows 6, 8, 9 relabelled 2026-11-16: added/removed paragraphs whose partner fuzzy missed; first verdicts trusted fuzzy's 'no partner'); dates in the file were Excel-mangled (12/31/24), fixed to ISO: edit it in VS Code, not Excel; "reworded" includes grammar knock-ons of period updates (materiality is the classifier's job). Some section labels are clean.py artifacts ("Table of Contents" for COP, sentence fragments for JPM).
- Trading days from earnings to filing: 0 for GOOGL, MSFT, NVDA (and COP 10-Qs); 1-2 XOM, KO, PG 10-Qs (PG releases pre-market, files after close); 4 CVX; 6-25 JPM, MS, WMT and all 10-Ks.
- Betas vs SPY near zero for KO, PG, XOM (staples / energy decoupled from SPY in 2025-26; XLP beta -0.03 since mid-2025): real, not a data error (KO vs XLP ~0.9 throughout). Sector ETF contains the stock (MSFT/NVDA in XLK, XOM in XLE), which biases sector-model CARs toward zero.
- MS 10-Q 2024-09-30 window holds the post-election bank rally (+9.5% vs SPY, +3.8% vs XLF).
- XOM successor registrant ExxonMobil Holdings Corp (CIK 2115436) from 2026-07-01: earnings 8-Ks there (`EXTRA_CIKS`); ingest.py will need it for XOM 10-Qs after Q2 2026.
- Embedding vs fuzzy: embeddings fix topic look-alikes (M365 Commercial vs Consumer); before direction masking they lost short sentences whose verb flipped (Xbox increased -> Azure increased). Cross-section matches ~60% right at any cosine >= 0.92 (segment templates, noisy headings). JPM lead-in sentences ("...driven by:") match their own bullets in the 0.76-0.86 band.
- pandas 3: `DataFrame.stack()` keeps NaN; filter after stacking.
- `word_count` in the manifest is on raw text (includes that overrun).
- 10-K vs 10-Q MD&A length: ~1x for MSFT, GOOGL, NVDA; 1.3-2.2x for most; 3.9x for XOM.
